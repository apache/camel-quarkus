== Camel Quarkus AWS 2 Athena Integration Tests

integration tests for Camel Quarkus AWS 2 Athena extension.

=== Credential Configuration

You can configure AWS credentials via environment variables:
* `AWS_ACCESS_KEY`
* `AWS_SECRET_KEY`
* `AWS_REGION`
* `AWS_USE_DEFAULT_CREDENTIALS_PROVIDER` (set to `true` to use the default AWS credentials provider chain)
