== Test modules

The test modules are WASI Preview 1 command modules, written in the WebAssembly text format in `src/main/wat`:

* `upper.wat` copies its standard input to its standard output in upper case
* `error.wat` writes `this is an error` to its standard error and exits with code 3

The build compiles them to `wasm/modules/*.wasm` on the classpath with `wat2wasm` from `run.endive:wabt`.
