== Camel Quarkus OData Integration Tests

By default the OData integration tests use WireMock to stub the interactions with the public
https://services.odata.org/V4/TripPinServiceRW/[TripPin] OData V4 service.

To run the tests against the real service, set the following environment variable:

[source,shell]
----
export ODATA_BASE_URL=https://services.odata.org
----

If the WireMock stub recordings need updating, then remove the existing files from `src/test/resources/mappings` and run
tests with either:

System property `-Dwiremock.record=true`

Or

Set environment variable `WIREMOCK_RECORD=true`
